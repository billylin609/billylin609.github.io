# billylin609.github.io

Welcome to my person github page. This is my development page for my person website. To make the develop flow a bit easier

## Building

The site is a [Quarto](https://quarto.org) project. Install Quarto, then:

```bash
quarto preview          # live-reloading dev server
quarto render           # build into _site/
```

Pushing to `main` builds and deploys via `.github/workflows/publish.yml`.

See [AUTHORING.md](AUTHORING.md) for how to add a page and how to write math,
figures, tables and cross-references.
